# Baseball-Analytics
"A collection of baseball-related projects using Python and SQL — covering data analysis, visualization, modeling, and anything else baseball-related I build along the way."

## Projects
### [OPS vs Wins Analysis](./ops-wins-analysis/)
Explores whether OPS predicts team wins in MLB. Built a multiple regression model (OPS + Runs Allowed) that explains 76% of win variation, compared to just 17% using OPS alone.
